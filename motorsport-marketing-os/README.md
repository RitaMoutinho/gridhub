# Motorsport Marketing OS

Sistema-conceito para gestão de marketing de uma equipe de automobilismo.

## Como abrir
1. Extraia a pasta.
2. Abra `index.html` no navegador.

## Módulos
- Dashboard
- Race Weekend
- Patrocinadores
- Content Planner
- Analytics
- Asset Library
- Relatórios
- Perfil

## Interações
- Criar e concluir tarefas.
- Cadastrar patrocinadores.
- Criar itens no planner.
- Adicionar ativos à biblioteca.
- Filtrar conteúdo e ativos.
- Exportar Analytics em CSV.
- Gerar e baixar resumo de relatório.
- Estado salvo no navegador com `localStorage`.

Os dados são fictícios e servem como demonstração de produto/portfólio.
